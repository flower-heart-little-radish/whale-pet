# 🐋 工作鲸娘 · WorkBuddy 桌宠

挂在桌面右下角的 DeepSeek 鲸鱼娘（大肥鱼）。点她一下，就能看到 **WorkBuddy 还剩多少积分、现在是峰段还是谷段、离下次切换还有多久、今天用掉多少**；不管她的时候，她会自己蹦、转圈、张望、打哈欠。

基于 **Rust + Tauri 2** 重写（原 Electron 版已归档），透明置顶窗口、按像素级轮廓判断点击穿透、原生拖拽。

---

## 功能

按重要程度排列：

### 1. WorkBuddy 剩余积分显示

单击她弹出积分卡片，最醒目的一行是**当前可用余额**（带小数）。

**数据由你自己接**：本仓库不含任何取数/鉴权代码，只留了一个约定和一份模板。见下方[「取数怎么接」](#取数怎么接)。

### 2. DeepSeek 峰谷计时

卡片顶部是一条**峰谷带**，整条按当前时段高亮：

| 状态 | 颜色 | 含义 |
| --- | --- | --- |
| 峰段 | 橙 | 计费倍率高 |
| 谷段 | 青 | 计费倍率低 |

右侧是**距下一次切换的倒计时**（精确到分）与进度条，规则按 DeepSeek 官方公告（2026-08-23 起生效）。

### 3. 今日与近期积分使用

卡片中部给出两个数字：

- **今日已用**：当天累计消耗
- **近 7 日**：滚动 7 天总量，下方附 7 根迷你柱状图，能一眼看出哪天消耗突兀

### 4. 动作与互动

- **单击**：开 / 收积分卡片
- **双击**：Flash ⇄ Pro 切换
- **拖拽**：松手靠近屏幕四边（200 px 内）自动吸附
- **滚轮**：缩放 60%–180%，两种形象各自记忆
- **右键**：完整菜单（动作 / 形象 / 切换间隔 / 大小 / 置顶 / 贴边 / 自启 / 刷新 / 快捷方式 / 说明 / 隐藏 / 退出）
- **不管她**：空闲一会儿会自己动；超过设定时长自动切到 Pro 立绘

**16 种可点播动作**：跳一下、摇一摇、转个圈、伸懒腰、歪一下、跳个舞、左右张望、打个哈欠、探个头、鞠个躬、转两圈、害羞、生气、摸鱼、吃小鱼干、换个姿态。

形象分两种：`Flash` = Q 版（小巧省地方，默认），`Pro` = 全身立绘（含 4 种姿态）。

### 5. 其它

- 托盘菜单与桌宠右键菜单同源，托盘提供「显示/隐藏桌宠」开关
- 开机自启（写注册表 Run 项，可在菜单里关）
- 单实例运行；配置持久化到 `%APPDATA%\com.whalepet.desktop\config.json`
- 积分自动刷新：WorkBuddy 在跑时 120 秒一次，没在跑时降到 10 分钟

## 运行

### 直接用（Windows）

解压后双击 `启动桌宠.cmd`。目录里需要：

```
whale-pet/
├── whale-pet.exe      主程序
├── engine/            取数模块（需要你自己填，见下节）
├── config.json        初始配置
└── 启动桌宠.cmd
```

不填 `engine/` 也能跑：动作、拖拽、缩放、菜单、峰谷计时全部正常，只有积分数字显示 `—`。

首次运行前请确认装了 Python 3，或在 `config.json` 的 `python` 字段里写死解释器路径。

### 从源码构建

需要 Rust 工具链 + MSVC Build Tools + WebView2 运行时（Win11 自带）。

```bash
cd whale-pet-tauri/src-tauri
cargo build --release
```

产物在 `src-tauri/target/release/whale-pet.exe`。把 `whale-pet.exe` 和 `whale-pet-tauri/engine/` 复制到同一个目录即可运行。

> 改完前端记得 `touch src-tauri/build.rs` 再编译——Tauri 不会因为 `../src` 变了就重新嵌入资源。

## 取数怎么接

主程序不关心数据来源，它只做一件事：**执行 `engine/credit_probe.py`，读标准输出的 JSON**。

```
python engine/credit_probe.py             # 正常取数
python engine/credit_probe.py --no-remote # 只读本地用量
```

三条路，任选：

### 1. 自己填 token

打开 `whale-pet-tauri/engine/EXAMPLE_probe.py`，填上 `TOKEN` 和 `BASE_URL`，改成交互调用，重命名为 `credit_probe.py`。最省事，但令牌过期后要手动换。

### 2. 自己丢一个脚本进去

任何能打印出下面这段 JSON 的脚本都可以，命名成 `credit_probe.py` 放进 `engine/`：

```json
{
  "ok": true,
  "ts": 1730000000000,
  "balance": 1234.56,
  "local": {
    "today": 12.34,
    "week": 88.80,
    "by_day": [{"date": "2026-11-01", "used": 3.21}]
  },
  "notes": "",
  "elapsed_ms": 120
}
```

| 字段 | 含义 | 缺失后果 |
| --- | --- | --- |
| `balance` | 剩余积分 | 显示 `—` |
| `local.today` | 今日已用 | 留空 |
| `local.week` | 近 7 日合计 | 留空 |
| `local.by_day` | 7 日柱状图（按日期升序） | 不画柱子 |
| `notes` | 出错提示文案 | 不显示 |

峰谷时段和倒计时由前端计算（`src/pricing.js`），**脚本不用管**。

### 3. 让你的 AI 助手改

把 `EXAMPLE_probe.py` 顶部的注释整段丢给 AI，说明你的数据来源和鉴权方式，让它按格式实现——那段注释就是完整的接口约定。

## 几个实现要点

**拖拽**：不是 JS 每帧挪窗口，而是 Rust 里 `GetCursorPos` → `SetWindowPos`，4 ms 一拍。绕开了 WebView 的提交开销，快速拖动也不掉帧。

**点击穿透**：窗口本身铺满 440×760，但只有在她的像素轮廓上才接收鼠标。前端每 250 ms 上报一次包围盒 + 40×40 的透明掩膜，Rust 侧按光标位置查表决定是否穿透。

**右键菜单是独立窗口**：菜单画在她的窗口里会被边界裁掉（她靠屏幕顶端时，窗口大半在屏幕外）。所以菜单单独开一个透明窗口，位置跟着光标走，出屏自动翻转。

**DPI**：本机 125% 缩放下，创建窗口时给的尺寸会被当成物理像素。所以先在运行时读到真实缩放比，再按 `设计尺寸 × 缩放` 重设一次，否则整个页面的坐标系都是错的。

## 已知限制

- 仅 Windows（依赖 Win32 的窗口样式与 DWM 接口）
- 开箱只显示 `—`，需要按「取数怎么接」自行补 `engine/credit_probe.py`
- 桌宠窗口比内容大一圈，系统会在窗口边界画一条淡边——已把内容往里收，尽量避开，但无法彻底消除
